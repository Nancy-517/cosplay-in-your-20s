# 需求文档

## 1. 应用概述

### 1.1 应用名称
人生地图 Life Map

### 1.2 应用描述
面向中国青年的角色扮演式生涯博弈移动端应用。用户选择与自身成长处境相关的「人生地图」，在多轮高压选择和多方博弈中体验不同决策带来的结果。系统根据用户选择路径生成关系结算、人格标签、隐藏代价与平行人生结局，帮助青年在低风险互动体验中理解成长选择的复杂性。这是社会场景预演工具，非娱乐游戏或心理测评。

### 1.3 视觉风格
手写笔记本风格：手写字体、单色纹理、灰度调色板、强调排版层次结构、模拟笔记本质感。囚徒困境博弈时画风变暗，结算庭审场景使用深棕色。

## 2. 用户与使用场景

### 2.1 目标用户
中国青年群体，面临保研考研、实习争夺、入职适应、亲密关系、返乡创业等成长选择场景。

### 2.2 核心使用场景
用户在面临重要人生选择前或选择后，通过角色扮演式博弈体验不同决策路径的结果，理解成长选择的复杂性与代价，进行自我反思与成长。

## 3. 页面结构与功能说明

### 3.1 页面结构

```
├── 首页/地图大厅
├── 角色进入/局势概览页
├── 许愿页
├── 游戏主流程页
│   ├── 第1轮：资料共享危机
│   ├── 第2轮：导师信息互通
│   ├── 第3轮：囚徒困境
│   ├── 第4轮：盟友失误救援
│   ├── 第5轮：最后入口争夺
│   └── 第6轮：摊牌
└── 结局页
    ├── 结算庭审
    ├── 代价清单
    ├── 命运档案
    └── 心愿便利贴/留言墙
```

### 3.2 首页/地图大厅

#### 3.2.1 功能说明
  - 展示Life Map全景地图
  - 列出可选地图：保研之争、实习争夺、入职适应、亲密关系、家庭沟通、创业团队、合租室友、科研竞赛、社团竞选
  - 仅「保研之争」可进入，其他地图标注「即将开放」
  - 展示简要游戏说明
  - 点击「保研之争」进入角色进入页

### 3.3 角色进入/局势概览页

#### 3.3.1 功能说明
  - 展示人物关系图（复杂关系网络可视化）
  - 展示核心人物信息：
    - 玩家（自己）
    - 林亦然：同一导师组竞争者，表面友善，实则竞争激烈
    - 许知夏：信息灵通的学姐，掌握核心资源
    - 沈砚：低调但实力强的暗马，行动难以预测
    - 导师：关键裁判，决定最终机会点分配
  - 展示每个NPC的公开信息和隐藏特质提示
  - 展示玩家初始资源：
    - 信息卡×3
    - 信任标记×2
    - 机会点×1
    - 压力值：30
    - 声誉值：60
  - 展示公开目标：顺利保研上岸、维持体面关系
  - 展示私密目标（随机抽取2张）：例如「在不暴露自己信息优势的前提下完成保研」或「与沈砚建立真实友谊」
  - 点击「开始游戏」按钮进入许愿页

### 3.4 许愿页

#### 3.4.1 功能说明
  - 展示文案：「在游戏开始之前，许个愿吧～就像你刚来到大学，未谙世事，拥有所有期待与想象那样……」
  - 提供输入框，玩家输入愿望
  - 点击「踏入这场局」按钮进入游戏主流程

### 3.5 游戏主流程页

#### 3.5.1 整体流程
游戏共6轮博弈，每轮结构：
  1. 展示公开事件（全体可见）
  2. 展示玩家收到的私密信息/线索卡
  3. 玩家选择行动卡 + 选择对象 + 选择表达方式
  4. 系统公布部分结果
  5. 展示NPC反应（对话气泡/状态变化）
  6. 更新资源数值

#### 3.5.2 第1轮：资料共享危机
  - 公开事件：「导师组即将公布夏令营名额，名额只有2个，共4人竞争。」
  - 私密信息：玩家收到一份关键复试资料
  - 行动选择：
    - 选择对象：林亦然/许知夏/沈砚/全体群聊/导师窗口
    - 选择行动：共享/试探/结盟/保留/谣言
    - 选择表达方式：直接/委婉/模糊/强势/沉默
  - 系统公布部分结果
  - 展示NPC反应
  - 更新资源数值

#### 3.5.3 第2轮：导师信息互通
  - 公开事件：「导师约谈时间表公布，某人被优先约谈。」
  - 沈砚发出暗示（玩家可追问或忽略）
  - 行动选择：是否追问沈砚
  - 系统公布部分结果
  - 展示NPC反应
  - 更新资源数值

#### 3.5.4 第3轮：囚徒困境
  - 画风变暗
  - 插入梦境叙事：「这一天晚上，你做了一个梦……每个人都被关在一个立方体里……」
  - 公开事件：所有人手里有部分资料，共享则共赢，隐瞒则自利但群体受损
  - 核心资料共享博弈：
    - 选择行动：共享/延迟共享/部分共享/私下给盟友
  - 系统根据前面的信任记录影响后续反应
  - 系统公布部分结果
  - 展示NPC反应
  - 更新资源数值

#### 3.5.5 第4轮：盟友失误救援
  - 公开事件：「林亦然材料出现漏洞，你是否帮忙补救？」
  - 行动选择：托举/抢占
  - 结盟机制：可邀请某人进入私聊小房间
  - 系统公布部分结果
  - 展示NPC反应
  - 更新资源数值

#### 3.5.6 第5轮：最后入口争夺
  - 公开事件：「推荐信名额突然减少为1个。」
  - 行动选择：抢占/澄清/合作
  - 系统根据声誉值影响NPC反应
  - 系统公布部分结果
  - 展示NPC反应
  - 更新资源数值

#### 3.5.7 第6轮：摊牌
  - 圆桌复盘会
  - 所有隐藏信息公开
  - 每人亮出自己的资源卡
  - 系统判定最终结局
  - 进入结局页

#### 3.5.8 行动卡系统
每轮可选行动：
  - 共享：公开信息，增加群体信任，减少个人信息差
  - 试探：询问某人关键信息，可能得线索也可能引发警惕
  - 结盟：与某人达成私下互助，获短期保护，被他人怀疑
  - 保留：暂不共享，保住优势，信任下降
  - 抢占：优先申请机会，资源上升，声誉可能受损
  - 澄清：公开解释行为，降低误会，但暴露部分策略
  - 托举：帮助他人，自己短期吃亏，长期信任上升
  - 谣言：散布模糊信息，制造混乱

行动对象：林亦然/许知夏/沈砚/全体群聊/导师窗口

表达方式：直接/委婉/模糊/强势/沉默

#### 3.5.9 资源系统
  - 信息卡：可交换/隐瞒/公开/伪装成不重要
  - 信任标记：可解锁私聊和联盟
  - 机会点：导师沟通/推荐信/夏令营入口，决定最终结果
  - 压力值（0-100）：高压力无法选择「长期主义」行动
  - 声誉值（0-100）：影响结局复盘与他人评价

### 3.6 结局页

#### 3.6.1 结算庭审
  - 深棕色法庭风格界面
  - 展示所有玩家（含NPC）正面面对
  - 系统（法官）宣读判决书：获得了什么/失去了什么
  - 展示关键证据线索卡，例如：
    - 「你在第2轮没有追问沈砚的暗示，导致错过了提前沟通窗口。」
    - 「你在第3轮延迟共享资料，林亦然从那一刻开始不再主动给你信息。」
    - 「你在第5轮选择公开澄清，虽然失去了一部分效率，但保住了群体信任。」
  - 点击「下一步」进入代价清单

#### 3.6.2 代价清单（Cost List）
  - 列出每个关键决策的得与失
  - 时间轴格式：轮次 → 行动 → 代价/收益
  - 点击「下一步」进入命运档案

#### 3.6.3 命运档案
  - 根据决策路径生成人格标签（2-3个）
  - 例如：「信息控制者」「表面合作者」「真实同行者」「孤狼策略家」等
  - 展示简短模糊的人格解读
  - 点击「下一步」进入心愿便利贴/留言墙

#### 3.6.4 心愿便利贴/留言墙
  - 展示玩家开始时写的愿望
  - 系统反问：
    - 「你是否曾经动摇过——」
    - 「我当时为什么那么选？」
    - 「如果我全程合作，会不会被利用？」
    - 「如果我全程自保，会不会赢但失去信任？」
  - 大树意象：树叶由便利贴组成，每片叶子是一个玩家的留言
  - 展示其他用户的真实留言（匿名）
  - 玩家输入自己的感悟，提交后挂到树上
  - 点击随机叶子可查看他人留言
  - 结尾文案：「不管怎么样，不管得失如何，你都在二十岁，又成长了一点。」
  - 点击「返回首页」回到地图大厅

## 4. 业务规则与逻辑

### 4.1 私密目标随机抽取规则
  - 进入角色进入页时，系统从预设私密目标池中随机抽取2张
  - 私密目标示例：「在不暴露自己信息优势的前提下完成保研」「与沈砚建立真实友谊」

### 4.2 行动选择影响规则
  - 每轮玩家选择行动卡、对象、表达方式后，系统根据选择更新资源数值
  - 不同行动对资源的影响：
    - 共享：信任标记+1，信息卡-1
    - 试探：可能获得线索卡，声誉值-5
    - 结盟：信任标记+2，声誉值-10
    - 保留：信任标记-1
    - 抢占：机会点+1，声誉值-15
    - 澄清：声誉值+10，信息卡-1
    - 托举：信任标记+2，机会点-1
    - 谣言：压力值+10，声誉值-20

### 4.3 NPC反应规则
  - 系统根据玩家行动和当前资源数值生成NPC反应
  - 前面轮次的信任记录影响后续轮次NPC的反应
  - 声誉值影响第5轮NPC反应

### 4.4 压力值影响规则
  - 压力值高于70时，无法选择「长期主义」行动（如托举、澄清）

### 4.5 结局判定规则
  - 第6轮摊牌后，系统根据玩家最终资源数值（机会点、信任标记、声誉值）判定结局
  - 结局类型包括但不限于：成功保研且维持关系、成功保研但失去信任、保研失败但保住声誉、保研失败且关系破裂

### 4.6 人格标签生成规则
  - 系统根据玩家6轮决策路径生成2-3个人格标签
  - 标签示例：「信息控制者」「表面合作者」「真实同行者」「孤狼策略家」「利他主义者」「机会主义者」

### 4.7 便利贴留言存储规则
  - 玩家提交留言后，系统将留言内容匿名存储到后端数据库
  - 留言墙展示所有用户的匿名留言
  - 点击随机叶子时，系统从数据库中随机抽取一条留言展示

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 玩家在许愿页未输入愿望直接点击「踏入这场局」 | 提示「请输入你的愿望」，不允许进入游戏 |
| 玩家在游戏主流程中未选择行动卡直接点击「下一步」 | 提示「请选择行动」，不允许进入下一轮 |
| 玩家在心愿便利贴页未输入感悟直接点击「提交」 | 提示「请输入你的感悟」，不允许提交 |
| 玩家在游戏过程中退出应用 | 不保存游戏进度，下次进入从首页开始 |
| 便利贴留言内容为空 | 提示「请输入内容」，不允许提交 |
| 便利贴留言内容超过200字 | 提示「留言不得超过200字」，不允许提交 |
| 后端数据库连接失败 | 提示「网络异常，请稍后再试」，玩家可继续游戏但无法查看他人留言 |

## 6. 验收标准

1. 用户打开应用，进入首页/地图大厅，点击「保研之争」地图
2. 用户查看角色进入/局势概览页，了解人物关系、初始资源、目标，点击「开始游戏」
3. 用户在许愿页输入愿望，点击「踏入这场局」
4. 用户完成6轮博弈，每轮选择行动卡、对象、表达方式，查看NPC反应和资源数值更新
5. 用户进入结局页，依次查看结算庭审、代价清单、命运档案
6. 用户在心愿便利贴/留言墙输入感悟并提交，查看他人留言，点击「返回首页」
