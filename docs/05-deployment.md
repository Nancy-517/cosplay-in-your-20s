# 05 Deployment Guide

## 项目运行环境

本项目需要 Node.js 和 npm。

## 本地启动

```bash
npm install
npm run dev
```

## 构建检查

```bash
npm run build
```

## 环境变量

参考 `.env.example` 文件配置：

```txt
AI_API_KEY=your_api_key_here
AI_BASE_URL=your_ai_base_url_here
NEXT_PUBLIC_FEEDBACK_URL=https://example.com/feedback
```
